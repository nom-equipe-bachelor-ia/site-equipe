## Workflow

issue → branche → commits → pull request → revue → merge

- `main` est protégée : toute modification passe par une pull request approuvée (1 approbation).
- Une issue par tâche ; chaque PR contient `Closes #numero`.
- Fusion en **Squash and merge**.

## Conventions

- **Branches** : `type/numero-description` (ex. `feat/2-section-lea`)
- **Commits** : `type: description` (ex. `feat: ajoute la section de Léa`)
- **Types** : `feat` (ajout), `fix` (correction), `style` (CSS), `docs` (README)
- **Pull requests** : titre clair + `Closes #numero`
